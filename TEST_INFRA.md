# Test Infrastructure & Plan: Open Hub (by Anarchy)

## Test Framework & Runner
- **Framework**: Node.js native E2E & Contract Test Runner (`node /home/antigravity/tests/e2e/run-e2e.mjs`) using live HTTP `fetch` against `http://localhost:3000` (auto-starting the Next.js server if not already listening), HTML/DOM inspection, HTTP security header verification, and TypeScript/React component contract & behavioral verification.
- **How to run all tests**: `node /home/antigravity/tests/e2e/run-e2e.mjs`
- **How to run a single test file**: `node /home/antigravity/tests/e2e/run-e2e.mjs --tier=1` (or `--feature=F1`, `--tier=2`, `--tier=3`, `--tier=4`)

## Server / Process Lifecycle
- **How to start the application**: `npm run dev` (or `npx next dev -p 3000`) in `/home/antigravity`. The E2E runner checks `http://localhost:3000` and automatically spawns `npx next dev -p 3000` if port 3000 is not yet listening.
- **Port(s)**: `3000`
- **Health check / readiness signal**: HTTP `200 OK` on `GET http://localhost:3000/` with HTML body containing `OPEN HUB`.
- **How to stop cleanly**: Process cleanup on runner exit (if spawned by the runner).

## Test Helpers & Fixtures
- `tests/e2e/run-e2e.mjs` — Main CLI entry point, server readiness probe, test registry, assertion library, and summary reporter.
- `tests/e2e/tier1-features.mjs` — Tier 1 Feature Coverage tests (>= 5 tests per feature across F1–F13 = >= 65 tests).
- `tests/e2e/tier2-boundaries.mjs` — Tier 2 Boundary & Corner Cases (>= 5 tests per feature across F1–F13 = >= 65 tests).
- `tests/e2e/tier3-combinations.mjs` — Tier 3 Cross-Feature Pairwise Combinations (>= 15 tests).
- `tests/e2e/tier4-journeys.mjs` — Tier 4 Real-World Application User Journeys (>= 7 tests).
